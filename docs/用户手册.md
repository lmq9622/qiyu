# 栖语 用户手册（v0.0.17）

本手册对应本仓库发布的 `v0.0.17`（`0.0.x` 历史线最后一版，不含 MiniMind 小脑模块）。
仓库里的 `PROJECT_LOG.md` 记录了这一版是怎么一步步做出来的，本文只讲**怎么用**。

---

## 1. 安装与启动

### 方式 A：用发布包（推荐给只想起步就用的）

1. 到本仓库 Release 下载 `Qiyu-0.0.17-win64.exe`（单文件，约 100+ MB）。
2. 放到任意目录，双击运行。Windows 可能弹出 SmartScreen 提示（exe 未做代码签名）：
   「更多信息 → 仍要运行」。
3. 程序会自动在后台启动服务（`127.0.0.1:8765`），就绪后弹出应用窗口「栖语demo · AI 伴侣」。
   首次启动需要几秒到几十秒，窗口没出来先别重复双击。

运行数据写在用户目录：`%USERPROFILE%\.ai_companion\`（日志 `client.log`、`backend.log`，数据 `data\`）。

### 方式 B：用源码

```bash
pip install -r requirements.txt
copy .env.example .env      # 然后按第 2 节填 LLM 配置
python client.py            # 桌面窗口
```

只想开网页版：`python demo.py`，然后浏览器打开 <http://127.0.0.1:8765/>。
想连 Letta / 网关 / RAG 监控一起拉起：`python main.py`（需要自备 PostgreSQL）。

## 2. 配置模型（必做）

栖语**不内置模型**，必须先告诉它去哪儿取回答。

**在界面里配（exe 用户用这个）**

1. 左侧栏 →「设置」→「LLM 设置」；
2. 选一个预设（DeepSeek / 智谱 GLM / MiniMax / OpenAI / Claude / Gemini / Grok / Kimi / 小米 MiMo），
   或者选手填：`Base URL`、`模型名`、`API Key`；
3. 保存。界面会做一次连通性检测，通过之后再聊天。

配置持久化在 `%USERPROFILE%\.ai_companion\data\_runtime_settings.json`（源码模式在 `项目目录\data\`）。

**在 .env 里配（源码用户可选）**

```ini
LLM_BASE_URL=http://127.0.0.1:8081/v1
LLM_API_KEY=sk-no-key-required
LLM_MODEL=你的模型名
```

**接本机模型**：只要你的推理服务提供 OpenAI 兼容接口（llama.cpp server、Ollama 的 OpenAI 兼容端点等），
把 Base URL 指过去即可，比如 `http://127.0.0.1:8081/v1`。

**路由设置**：可单独指定「路由模型」用于判断该直答还是该思考/联网，留空则复用主模型。

## 3. 界面导览

左侧栏：

- **对话**：主聊天区。消息可以分多条气泡（第一反应 / 陈述 / 提问 / 补一句 / 表情），支持图片。
- **角色工坊**：创建和管理角色，见第 4 节。
- **设置**：六个标签页 —— LLM 设置 / 路由设置 / 知识库 / 外部通讯 / 记忆标签 / 外观。
- **记忆面板**：查看、增删长期记忆与用户档案，见第 5 节。
- **刷新数据**：重新拉取角色、记忆、通道状态等。

---

## 4. 角色工坊

一个角色就是一张「人设卡」，字段含义：

| 字段 | 含义 |
|---|---|
| 名称 / 一句话简介 | 显示用，例如「小栖 · 平级朋友，想聊就聊」 |
| 人设（persona） | 最关键的提示词：它是谁、住哪、什么脾气、怎么说话 |
| 用户设定（human） | 它眼里「你」是谁、你们是什么关系 |
| 记忆提示（memory_prompt） | 提醒它该怎么用记忆（例如「自然带出，别刻意表现关心」） |
| 语气 / emoji 频率 | 控制表情和语气词的使用 |
| 关键词 / 标签 | 便于分类与检索 |
| 头像 | 上传图片，或用内置头像 |

- **AI 生成人设**：给一句话需求，让模型流式生成完整人设草稿，再手动改。
- **切换角色**：在对话页选择当前角色；每个角色的记忆、关系、主动消息都是独立记账的。
- **多角色建议**：不同人设回合制回测过（12 人设 × 场景），人设写得越具体，越不像「AI 助手」。

---

## 5. 记忆系统

- 聊天内容会自动落库，并按用户档案 / 长期记忆 / 每日摘要分层组织。
- 「记忆面板」可以查看某条记忆、手动新增、删除、按标签筛选；重要的事也可以自己写进去。
- 「设置 → 记忆标签」管理标签体系。
- 「设置 → 外观」调整界面主题。
- 记忆文件都在数据目录里（见第 10 节），想重开一段关系直接清空对应文件即可。

---

## 6. 知识库（RAG）

让角色读你自己的资料（设定集、笔记、PDF 手册等）。

1. 「设置 → 知识库」可以查看已索引文档，也可以指定路径索引；
2. 也可以把文件丢进监控目录，默认是 `RAG_WATCH_DIR`（`./data/uploads`），
   用 `python rag/indexer.py watch` 或 `python main.py` 启动监控后自动入库；
3. 支持格式：`.txt`、`.md`、`.pdf`、`.docx`、`.doc`；
4. 检索用本地 `BAAI/bge-small-zh-v1.5` 做向量化（首次使用会联网下载模型），
   默认用内置 numpy 记忆库，不依赖外部向量数据库（Qdrant 可选）。

命令行也能用：

```bash
python rag/indexer.py index <路径>
python rag/indexer.py search "关键词"
```

## 7. 联网与工具

直接在对话里说「帮我查一下 / 找找 / 比个价 / 找张图」即可。系统会真实执行搜索或打开链接，
把**真实结果**交给模型再回复；失败时也会如实说明，不会假装已经查到。

---

## 8. 主动消息

- 每天 09:00–22:00 之间，角色会按好感度随机主动找你（好感度越高越频繁）；
- 深夜概率很低，但人设偏「外向 / 爱分享」会加成；
- 你长时间不回，下次聊天角色会自然把这件事带出来（在意、失落、追问），而不是发系统提醒。

---

## 9. 微信外部通讯（可选，有风险）

「设置 → 外部通讯」支持多种接入方式，差别如下：

| 通道 | 说明 | 稳定性 |
|---|---|---|
| ClawBot | 走官方协议，扫码绑定，支持多账号并行、消息置顶 | 较稳，推荐优先试 |
| Wechaty | Node 网关驱动（`wechaty/`，先跑 `wechaty\install.bat`），免费协议或 service token | 一般 |
| itchat | 单账号网页协议接管，**官方早已停止维护** | 差，随时可能失效 |
| 本机接管（wechatauto） | 驱动本机已登录的微信客户端（UI 自动化） | 需要不锁屏、微信版本兼容 |

使用流程：选择通道 → 启动 → 用手机微信扫码 → 状态变「在线」后即可收发。
「重置连接」会清空登录态，用于切换微信号。

- 可以把不同微信联系人映射到不同角色；
- **风险提示**：第三方协议接入微信存在账号被限制的可能，请用小号自测，不要用在主力号上。

## 10. 数据、备份与重置

| 位置 | 内容 |
|---|---|
| `%USERPROFILE%\.ai_companion\data\` | exe 模式的数据目录（记忆、会话、关系、主动消息状态、上传头像、运行时设置） |
| `<项目目录>\data\` | 源码模式的数据目录 |
| `%USERPROFILE%\.ai_companion\client.log`、`backend.log` | 客户端与后端日志，排障先看这里 |

- 环境变量 `QIYU_DATA_DIR` 可以覆盖数据目录位置；
- **备份**：直接整目录复制；
- **重置**：关掉程序后清空数据目录（或只删 `chat_history\`、`_runtime_settings.json` 等）；角色卡在 `characters\_user_characters.json`。

## 12. 常见问题

**Q：窗口没出来 / 一直转圈？**
看 `%USERPROFILE%\.ai_companion\backend.log`。最常见的原因是端口 8765 被别的程序占用了，
换一个端口再启动即可：

```bat
set QIYU_PORT=8888
Qiyu-0.0.17-win64.exe
```

（源码方式同理：先 `set QIYU_PORT=8888` 再 `python client.py`；其余情况多为依赖缺失。）

**Q：聊天报「连接失败」？**
模型 Base URL / Key / 模型名不对，或本机推理服务没起来。先用「设置 → LLM 设置」的连通性检测。

**Q：回复很慢或很敷衍？**
慢主要是你接的模型本身慢；敷衍通常是模型太小或人设写得太笼统。把「主模型」换成更强的，
并在人设里写清「说话短、有态度、别写小作文」。

**Q：Embedding 一直卡住？**
首次使用要下载 `BAAI/bge-small-zh-v1.5`，需要能访问 HuggingFace；离线环境请提前把模型放进缓存。

**Q：微信扫码登不上？**
itchat 已停维护，随时可能失败；本机接管通道要求微信客户端在前台且未锁屏；Wechaty 需要先装好 Node 依赖。

**Q：Windows Defender 报毒？**
PyInstaller 单文件 exe 常被误报（尤其做了加壳压缩）。加白名单即可；介意的话用源码方式运行。

---

## 13. 卸载

- exe 方式：删掉 exe 文件；如不再需要数据，删掉 `%USERPROFILE%\.ai_companion\` 整个目录。
- 源码方式：删掉项目目录；数据在项目 `data\` 与（如用过）用户目录。
- 微信通道：先在界面里「重置连接」退出登录，再删除相关目录。
